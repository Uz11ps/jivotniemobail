# Руководство для заказчика - Управление приложением

## Вход в админ-панель

1. Откройте админ-панель в браузере
2. Нажмите "Войти через Google"
3. Войдите с вашим Google аккаунтом
4. После первого входа администратор должен назначить вам роль (admin или editor)

## Управление категориями

### Добавление категории

1. Перейдите в раздел "Категории"
2. Нажмите "Добавить категорию"
3. Заполните поля:
   - **Название (RU)** - название на русском
   - **Название (EN)** - название на английском
   - **Иконка для таба** - загрузите изображение (PNG, JPG)
   - **Платная категория** - отметьте, если категория платная
   - **Product ID** - если категория платная, укажите Product ID из App Store Connect (например: `com.app.category.insects`)
   - **Видима** - отметьте, чтобы категория отображалась в приложении
4. Нажмите "Сохранить"

### Редактирование категории

1. Найдите нужную категорию в списке
2. Нажмите "Редактировать"
3. Внесите изменения
4. Нажмите "Сохранить"

### Изменение порядка категорий

1. В списке категорий перетащите категорию за иконку с тремя линиями
2. Порядок сохранится автоматически

### Удаление категории

1. Нажмите "Удалить" рядом с категорией
2. Подтвердите удаление

## Управление животными

### Добавление животного

1. Перейдите в раздел "Категории"
2. Выберите категорию, в которую хотите добавить животное
3. Нажмите "Перейти к животным"
4. Нажмите "Добавить животное"
5. Заполните поля:
   - **Название (RU)** - название на русском
   - **Название (EN)** - название на английском
   - **Превью (для сетки)** - изображение для карточки в сетке
   - **Фон** - фоновое изображение для детальной страницы
   - **Голос (RU)** - аудио файл с голосом на русском (опционально)
   - **Голос (EN)** - аудио файл с голосом на английском (опционально)
   - **Звук животного** - аудио файл со звуком животного (обязательно)
   - **Анимация (Lottie)** - файл анимации в формате .lottie или .json (опционально)
   - **Анимация (Video)** - видео файл с анимацией (опционально)
   - **Видимо** - отметьте, чтобы животное отображалось в приложении
6. Нажмите "Сохранить"

### Редактирование животного

1. Найдите нужное животное в списке
2. Нажмите "Редактировать"
3. Внесите изменения
4. Нажмите "Сохранить"

### Изменение порядка животных

1. В списке животных перетащите животное за иконку с тремя линиями
2. Порядок сохранится автоматически

## Управление офферами (Special Offers)

### Создание оффера

1. Перейдите в раздел "Офферы"
2. Нажмите "Добавить оффер"
3. Заполните поля:
   - **Заголовок (RU/EN)** - заголовок оффера
   - **Hero изображения** - добавьте до 3 изображений для оформления
   - **Элементы оффера** - добавьте элементы с:
     - Названием (RU/EN)
     - Product ID из App Store Connect
     - Бейджем "Выгодно" (опционально)
   - **Primary Product ID** - основной Product ID для кнопки покупки
   - **Активен** - отметьте, чтобы оффер отображался в приложении
4. Нажмите "Сохранить"

## Настройка IAP (In-App Purchases)

### Важно о ценах

**Цены нельзя изменить из админки!** Они настраиваются в App Store Connect.

В админке вы можете:
- Указать, какие категории платные
- Привязать категорию к Product ID из App Store Connect
- Управлять текстами и бейджами

### Настройка Product ID в App Store Connect

1. Войдите в App Store Connect
2. Перейдите в раздел "Мои приложения" → ваше приложение
3. Выберите "Функции" → "In-App Purchases"
4. Создайте новый продукт:
   - Тип: "Non-Consumable" (непотребляемый)
   - Reference Name: название категории
   - Product ID: например, `com.app.category.insects`
   - Цена: установите цену
5. Сохраните Product ID и используйте его в админке

## Просмотр аналитики

1. Перейдите в раздел "Аналитика"
2. Выберите период: День / Неделя / Месяц
3. Просмотрите графики:
   - Открытия категорий
   - Открытия животных
   - Топ категорий
   - Топ животных
   - Доходы

## Управление пользователями (только для админов)

1. Перейдите в раздел "Пользователи"
2. Найдите пользователя по email
3. Выберите роль: Editor или Admin
4. Изменения применятся автоматически

## Рекомендации по медиа-файлам

### Изображения
- Формат: PNG или JPG
- Иконки категорий: 100x100 пикселей
- Превью животных: 200x200 пикселей
- Фоны: 1024x1024 пикселей или больше

### Аудио
- Формат: MP3
- Битрейт: 128 kbps или выше
- Длительность голоса: до 5 секунд
- Длительность звука животного: до 10 секунд

### Анимации
- Lottie: формат .lottie или .json
- Видео: формат MP4, разрешение до 1080p

## Часто задаваемые вопросы

**Q: Как изменить цену категории?**  
A: Цену нужно изменить в App Store Connect. В админке можно только привязать другую категорию к другому Product ID.

**Q: Почему животное не отображается в приложении?**  
A: Проверьте, что у животного отмечено "Видимо" и оно добавлено в видимую категорию.

**Q: Как добавить новый язык?**  
A: Сейчас поддерживаются только русский и английский. Для добавления нового языка требуется обновление приложения.

**Q: Где хранятся загруженные файлы?**  
A: Все файлы хранятся в Firebase Storage и автоматически доступны в приложении.
