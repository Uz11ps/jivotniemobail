# Настройка IAP в App Store Connect

## Создание In-App Purchase продуктов

### Шаг 1: Создание продукта

1. Войдите в [App Store Connect](https://appstoreconnect.apple.com/)
2. Выберите ваше приложение
3. Перейдите в раздел "Функции" → "In-App Purchases"
4. Нажмите "+" для создания нового продукта

### Шаг 2: Настройка продукта

**Тип продукта:** Non-Consumable (Непотребляемый)

**Reference Name:** Название категории (например: "Насекомые")

**Product ID:** Уникальный идентификатор (например: `com.app.category.insects`)
- ⚠️ **Важно:** Этот ID должен совпадать с `iapProductId` в админке

**Цена:** Выберите цену из списка или установите свою
- ⚠️ **Важно:** Цену нельзя изменить из админки, только здесь

**Локализация:** Добавьте описание на русском и английском

### Шаг 3: Сохранение Product ID

После создания продукта:
1. Скопируйте Product ID
2. Войдите в админ-панель
3. Откройте категорию
4. Отметьте "Платная категория"
5. Вставьте Product ID в поле "Product ID (StoreKit)"
6. Сохраните

## Примеры Product ID

Рекомендуемый формат: `com.yourcompany.app.category.{category_name}`

Примеры:
- `com.app.category.insects` - Насекомые
- `com.app.category.transport` - Транспорт
- `com.app.category.fruits` - Фрукты
- `com.app.category.vegetables` - Овощи

## Создание оффера (Special Offer)

Для создания оффера с несколькими продуктами:

1. Создайте отдельные продукты для каждого элемента оффера
2. В админке создайте оффер:
   - Добавьте элементы с их Product ID
   - Укажите Primary Product ID (основной продукт для покупки)

## Тестирование покупок

### Sandbox тестирование

1. В App Store Connect создайте Sandbox тестовый аккаунт:
   - Users and Access → Sandbox Testers → "+"
   
2. На устройстве:
   - Settings → App Store → Sandbox Account
   - Войдите с тестовым аккаунтом

3. В приложении:
   - Покупки будут бесплатными
   - Транзакции будут видны в App Store Connect → Sales and Trends

### Важные замечания

- ⚠️ Sandbox покупки не работают на симуляторе, только на реальном устройстве
- ⚠️ После тестирования выйдите из Sandbox аккаунта
- ⚠️ Production покупки работают только после публикации приложения

## Проверка транзакций

1. App Store Connect → Sales and Trends
2. Фильтр по дате и продукту
3. Просмотр статистики продаж

## Восстановление покупок

Приложение автоматически поддерживает восстановление покупок через:
- Профиль → Мои покупки → Восстановить покупки

Это работает для всех устройств пользователя с одним Apple ID.
