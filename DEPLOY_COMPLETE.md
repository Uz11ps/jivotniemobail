## Примечание о сборке:

Production сборка (`npm run build`) падает с Bus error, вероятно из-за нехватки памяти на сервере. 
Приложение запущено в **dev режиме**, что работает нормально для разработки и тестирования.

Для production сборки:
- Увеличьте память сервера
- Или используйте более мощный сервер
- Или продолжайте использовать dev режим
