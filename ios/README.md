# iOS приложение - Дети и Животные

SwiftUI приложение для детей с категориями животных, анимациями и звуками.

## Требования

- Xcode 15.0+
- iOS 16.0+
- Swift 5.9+

## Установка зависимостей

```bash
cd DetiZhivotnieApp
swift package resolve
```

## Запуск

Откройте `DetiZhivotnieApp.xcodeproj` в Xcode и запустите проект.

## Структура

- `Sources/App/` - Точка входа приложения
- `Sources/Features/` - Функциональные модули
- `Sources/Services/` - Сервисы (Firebase, IAP, Audio)
- `Sources/UI/Components/` - Переиспользуемые UI компоненты
