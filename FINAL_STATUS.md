## Проблема

Next.js запускается и привязывается к порту, но не отвечает на HTTP запросы. Это может быть из-за:
- Компиляции страниц (может занять 5-10 минут)
- Ошибки при обработке первого запроса
- Проблемы с памятью на сервере (всего 1.9GB)

## Решение

### Вариант 1: Подождать компиляцию
Next.js компилирует страницы при первом запросе. Подождите 5-10 минут и проверьте снова.

### Вариант 2: Проверить логи
```bash
ssh root@168.222.193.86
pm2 logs deti-admin --lines 100
```

### Вариант 3: Перезапустить с большим временем ожидания
```bash
ssh root@168.222.193.86
pm2 restart deti-admin
# Подождите 5-10 минут
curl http://127.0.0.1:3000
```

### Вариант 4: Использовать production сборку (требует больше памяти)
Если dev режим не работает, можно попробовать production сборку, но она требует больше памяти.
